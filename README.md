# AI-Fluent at Work: programme concept and prototypes

A self-paced programme concept for early-career professionals aged 18–25 across Africa, with a Week 3 lesson, **The 5-Point Check**, and four clickable activities.

**Live site:** open the GitHub Pages link in this repository's About section.

## What's here

| File | What it is | Interaction |
|---|---|---|
| `index.html` | Programme overview, lesson flow and links to every activity | Start here |
| `wanjirus-choice.html` | Wanjiru's choice: four endings depending on whether she checks her AI cover letter | Branching story |
| `mark-claims.html` | Mark the claims: find the sentences in a LinkedIn draft that need checking | Tap to highlight |
| `which-check.html` | Which check?: sort ten AI mistakes into facts, figures, sources, tone or local fit | Tap to sort |
| `error-hunt.html` | Error Hunt: keep or fix each line of a side hustler's sale post | Keep or fix |
| `styles.css` | Shared colours, type and components, including light and dark modes | |

## Design principles

- **Explore, notice, understand, apply:** the four activities build one skill in that order.
- **Phone-first and self-paced:** one column, large tap targets, instant feedback, no facilitator needed.
- **Accessible:** keyboard-friendly, feedback in words as well as colour, light and dark modes.
- **Local by design:** scenarios set in Nairobi, Pretoria, Lagos, Kumasi and Kigali, with local currencies and payment methods.

## Production assumption

Each activity maps to an H5P content type (Branching Scenario, Mark the Words, Drag and Drop, Single Choice Set). These pages are plain HTML, CSS and JavaScript with no build step.
