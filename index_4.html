Why four different interactions

  • Explore consequences first, so learners care about checking (branching story).
  • Notice where mistakes hide before judging them (highlighting).
  • Understand what each check is for (sorting).
  • Apply all five checks to a whole draft (keep or fix).

Design notes

  • Phone-first: one column, large tap targets, no dragging.
  • No facilitator needed: every answer gets instant feedback that names the check.
  • Accessible: works by keyboard, feedback is written in words as well as colour, and light and dark modes are both designed.
  • Production assumption: each activity maps to an H5P content type (Branching Scenario, Mark the Words, Drag and Drop, Single Choice Set). If H5P isn’t available, the same logic runs as a simple web component like these.
